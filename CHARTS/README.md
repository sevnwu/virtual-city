## ⚠️ 已知限制（**引用这些图时请一并说明**）

- **单一种子** ⇒ 图上两条曲线是**一个样本**，不是统计结论；差异（−1.4%）**未经显著性检验**。
- **规模小** ⇒ 2,500 人起步，不是真实城市量级。
- **效应方向是负的** ⇒ 图中"政府层开启"一侧人口更少。原因是人口门槛排除了 3 个基建领域，
  剩余领域的拥堵上升；**这不应被读成"政府层有害"**，而应读成"门槛设定本身在起作用"。
- **人口迁移只有流入**（`migOutCum` 恒为 0）⇒ 模型无法表达人口流出与城市收缩。
  这是"净额式"表述的必然后果，已在 `RUN500_SPEC.md` §A5 记录。
- **长窗口经济无均衡** ⇒ `avgIncome` 在 200 年内增长约 37 倍，长期财政类结论需谨慎。

限制的完整清单见 `../../LIMITATIONS.md`。
