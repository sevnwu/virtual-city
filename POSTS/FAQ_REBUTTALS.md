# 质疑应答手册（FAQ / REBUTTALS）

> **⭐ 这是整套传播材料里最重要的一份。**
> **帖子一定会招来质疑 —— 而「能不能答得上」决定它是被认可，还是被当成骗子。**
>
> **三条铁律**：
> ① ⚠️ **每条答复【不超过 5 行】** —— 长了没人看
> ② ⚠️ **不会的就直说"不知道 / 没做"** —— 辩解比承认伤害大得多
> ③ ⭐ **被指出真错误 ⇒ 立刻承认 + 当场更新 `LIMITATIONS.md` + 在评论区贴出来**

## ① "这不就是 ABM / 微观仿真吗？有什么新的？"

**⚠️ 这是最可能被问的 —— 也是我们最可能答不上的一条。**

**诚实的分层回答**：

```
· 【个体层】—— ❌ 不新。ABM / 微观仿真做了几十年，这一层我们是继承的。
· 【制度层】—— 🟡 可能有一点新：我们把「政府」做成了有【预算约束】的行动者 ——
   税收 → 预算 → 维护 → 折旧 → 重建，是一条闭合回路（而不是外生参数）。
· 【反事实卫生】—— 🟡 这可能才是我们真正在意的：
   同种子 · 只改一个开关 · 三层判定（开关生效 / 状态量变 / 行为变），
   并且【把口径陷阱写成清单】。我们栽过：唯一显著的指标是个同义反复。
⇒ ⇒ ⭐ 结论：**个体层不新 · 我们赌的是【制度层 + 反事实卫生】。**
   ⚠️ 而这一条【可能是错的】—— 我们没做完整文献调研。若你知道已有工作做过同样的事，
   **请告诉我，那会帮我们省很多时间。**
```

**⚠️ 备选（若被追问"那你不就是包装了一下"）**：
```
也许。所以我们把限制清单（L-1~L-7）和样例数据都公开了 ——
如果包装能被验证、也能被证伪，那它至少不是空话。
```

## ② "你怎么知道它像真的？有验证吗？"

```
⭐ 诚实答：**没有系统验证。**
· 我们只有一个"给 1~2 个指标做公开统计对照"的方案（`REALITY_ANCHOR_PLAN.md`），**还没实施**。
· 第一个要做的对照是【学历分布】—— 而按我们的限制 L-1，**它大概率对不上**，
  而这本身就是有用的结果（把"内部观察"升级为"对真实世界的偏离"）。
⇒ ⇒ ⚠️ 所以正确表述是：**"它是一个沙盘，不是一个测量。"**
```

## ③ "参数是不是拍的？"

```
部分是。我们给每个参数标了【三态】：
· 【官方】—— 有政策文件依据。例：地铁建设门槛"市区常住人口 300 万以上"（国办发〔2018〕52号）
· 【平台】—— 有可引用的研究/规划文件。例：地市级"每 100~200 万人设 1~2 个市办综合医院"
· 【模型假设】—— 就是拍的。例：学校的 5 万人口门槛（我们查不到可引用的数值）
⇒ ⇒ ⚠️ 而【第三类占相当比例】—— 参数表里逐项标了，没有藏。
```

## ④ "数据哪来的？抄的吗？有没有隐私问题？"

```
· **凭空生成** —— 用程序模拟出来的，**不来自任何真实个体**。
· **没有一条记录对应真人** ⇒ **不存在隐私问题**。
· 姓名是生成的 · 事件是模拟的 · 数字是假的。
⇒ ⇒ ⚠️ 反过来也要说清：**"没有隐私问题"不等于"有代表性"** —— 它谁都不代表。
```

## ⑤ "这能预测未来吗？"

```
⭐ **不能。** 这是我们的第三句免责声明。
· 没有真实对照 ⇒ **不知道它偏多少 · 也不知道往哪偏**。
· 而且已知有【三条会让结论方向变反】的限制（学历年龄结构 · 口径歧义 · 迁移净额式）。
⇒ ⇒ ⚠️ **任何说"它能预测"的说法（包括我们自己说的）都是错的。**
```

## ⑥ "那它到底有什么用？"

```
⭐ **能做真实世界做不到的对照实验。**
· "如果给每个新生儿补贴 X 会怎样" —— 真实世界不能拿人做试验。
· "如果地铁维护欠付三年会怎样" —— 没人会为了做实验停掉地铁维护。
⇒ ⇒ ⚠️ 而用途是【生成假设和排查机制】，**不是【给出答案】**。
   它最有用的时候，是它告诉你"你这个政策的因果链其实断在第二环"。
```

## ⑦ "为什么不用 LLM？让 AI 扮演人不就行了？"

```
· **LLM 能写出一份像样的报告 · 但说不出"是哪个机制导致的"。**
  我们关心的是【机制归因】—— 而 LLM 的输出无法拆到具体因果链上。
· 而且我们要**反事实**：同种子 · 只改一个开关。LLM 的采样做不到这个。
⇒ ⇒ 🟡 但要说实话：**LLM 在多轮对话/态度层面比我们强得多** ——
   我们的个体只有 20 来个数值属性，没有语言。
```

## ⑧ "你怎么证明不是过拟合？"

```
⭐ **不能证明。**
· 没有真实对照 ⇒ "过拟合"这个概念在我们这里**甚至没有定义**（没有训练/测试划分）。
· 我们能做的只有：**同种子配对 + 跨种子置信区间**（K=10 · df=9 · 跨种子 t CI 作主结论）。
· ⚠️ 而这只能排除"随机噪声"，**排除不了"模型设定错了"**。
⇒ ⇒ 所以我们的结论一律降级表述为**"机制级"**，而不是"统计级"。
```

## ⑨（预备）"那你发的这些数字还有什么意义？"

```
意义在于【**方法是可检查的**】：
· 每个数字都有产物文件 · 每个陷阱都写在清单里 · 每条限制都有行号。
⇒ 你可以不同意我们的结论，但你能【复现我们的过程】并指出我们哪里错了。
⇒ ⇒ ⭐ 这比"请相信我们的预测"要好 —— 因为我们不要求你相信任何东西。
```

## ⑩（预备）"你们就是想融资吧？"

```
· 是。我们**没有资金也没有影响力**，这是我们公开这些东西的原因。
· ⚠️ 但**公开的东西里没有一个是为了融资而夸大的数字** —— 恰恰相反，
  我们把"会让结论反向"的三条限制放在了最前面。
⇒ ⇒ 如果你因为这份限制清单而觉得它可信 —— 那正是我们想要的效果。
```
