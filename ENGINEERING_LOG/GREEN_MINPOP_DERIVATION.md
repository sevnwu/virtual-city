## 一、⭐ 锚（**已查证 · 有 URL 与原文**）

**《国家园林城市标准》**「城市人均公园绿地面积」按**人均建设用地**分档：

| 人均建设用地 | 国家园林城市 | 生态园林城市 |
|---|---|---|
| **< 80 ㎡** | **≥ 7.50 ㎡/人** | ≥ 9.50 ㎡/人 |
| **80 ~ 100 ㎡** | ⭐ **≥ 8.00 ㎡/人** | ≥ 10.00 ㎡/人 |
| **> 100 ㎡** | **≥ 9.00 ㎡/人** | ≥ 11.00 ㎡/人 |

- **另**：**各城区人均公园绿地面积最小值 ≥ 5.00 ㎡/人**
- ⭐ **关键**：**8 ㎡/人 不是"发达城市的高线"· 而是【国家园林城市的最低要求】** ✓
- **来源**：[温州网政务频道转载《国家园林城市标准》](https://gov.66wz.com/system/2015/08/18/104546212.shtml)
  （**实测 HTTP 200 · 表格原文已抓取 · 2026-10-07**）

**三态标注建议**：⭐ **`官方`** —— **标准本身是官方文件**；
⚠ **但"用它反推门槛"是我们的推导** ⇒ **`note` 里要说清这一点**。

## 二、⭐⭐ 门槛值是**算出来的**（一道除法）

```
现状：`green` 1 级 = **500 公顷**（`gov_costs.json`：`unitPhysical.value = 500` · 单位 公顷）

反推：**500 公顷 ÷ 8 ㎡/人 = 62.5 万人**

⇒ ⇒ ⭐ **所以"要求 500 公顷绿地"对应的是【60 万人级城市】** ✓
```

**⇒ 建议值**：

```json
"minPopulation": 600000
```
（**取整到 60 万**；**62.5 万更精确 · 而 60 万更好读** —— **二者都可辩护**）

**`note` 建议写法**：
```
500 公顷 ÷ 8 ㎡/人（国家园林城市下限）= 62.5 万人 ⇒ 取 60 万。
即：要求 500 公顷绿地的城市，其规模下限应为 60 万人。
```

## 三、⚠ 而它同时暴露一个**量级问题**（值得记）

```
2,500 人城市被要求 **500 公顷**绿地
   而按 8 ㎡/人 ⇒ 2,500 人只需 **2 公顷**
⇒ ⚠ **差 250 倍**
```
⇒ ⭐ **这说明"2,500 人该不该有 500 公顷"是【门槛问题】· 而不是【单价问题】** ✓
⇒ ⚠ **而 `unitPhysical`（500 公顷）本身对应 60 万人级城市 · 对更小城市则仍偏大** ——
  **那是独立决策**（**本文件不主张改 `unitPhysical`**）。
