```

   ⇒ 全文件 **24 处**同式检查（结婚 `:479` · 工作 `:3676` · 生育 `:4687-4689` · 日程 `:8198` · 档案 `:8555`）

   ⇒ ⚠ **即：这不是显示问题 —— 它真的被模拟了 · 会进"一生轨迹"** ✓

   ⇒ **无条件下追加约会条目** ⇒ **追加到【监室日程】之上** ✓
```

## 二、修法（**两处同改 · 各加一条守卫**）

```js
// ① stepDates（L2736 附近 · 紧跟 alive 检查）
if (!city.alive[i] || !city.alive[j]) continue;
// ★ 在押者不参与任何约会/交往/分手/婚外情（判据同 L479/L3676/L4687：jailUntil > day）
//   ⚠ 与 routineOverlayDate 必须【同改】：这里管"模拟与一生轨迹"，那里管"日程显示"。
if (LV2('crime') && city.jailUntil && (city.jailUntil[i] > city.day || city.jailUntil[j] > city.day)) continue;

// ② routineOverlayDate（L8401 附近 · 紧跟 dt 守卫）
if (!dt || !st || !st.length) return st;
// ★ 在押者不追加约会条目（与 stepDates 同改 · 见 DETAINED_LOGIC_BUG.md）
if (LV2('crime') && city.jailUntil && city.jailUntil[i] > city.day) return st;
```
