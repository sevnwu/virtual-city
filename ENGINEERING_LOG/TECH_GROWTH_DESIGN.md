## 〇、一句话

```
引擎现在【没有"年"这个经济概念】：工资是行政公式（不含生产率）、死亡风险是常数生命表、
物价只有"通胀系数"而没有【价格水平】。
⇒ 本层加三样：① 全要素生产率趋势（进工资）② 死亡风险下降趋势（进生命表）③ 价格水平指数（给政府口径）。
⭐ 铁律：**开关关闭 = 逐字节不变**（判据 A 必须仍等于当前基线）。
```

## 一、接口（**照政府层提出的需求实现，不另起一套**）

| 接口 | 签名 | 用途 | 谁要 |
|---|---|---|---|
| 技术因子 | `CIV.cityTfpOf(year)` | 相对**基准年**的全要素生产率倍数 | 工资公式 |
| 价格水平 | `CIV.cityPriceLevelOf(year)` | 相对**基准年**的累积价格水平（P_0 = 1） | 政府层（名义/实际 treasury）· 成本表按年折算 · 税档指数化 |
| 目标期望寿命 | `CIV.cityE0Target(year)` | 该年的目标 e0（岁） | 生命表重建 |
| 口径导出 | `CIV.CITY_TECH_INFO` | 基准年 · 参数 · 是否启用（供报告与 UI） | 自证/审计 |

⭐ **基准年 = 仿真第 0 年**（即 `gov_costs.json` 里那些"元"的年份 = 2026 年口径）。
⇒ 所以 `year=0` 时 **TFP ≡ 1 · 价格水平 ≡ 1** ⇒ **t=0 时与旧行为逐位相同**（这是"关时不变"之外的第二道保险）。

## 二、参数（**三态标注 · 全部有来源或明确标为模型假设**）

### 2.1 生产率 / 工资趋势

| 参数 | 取值 | 依据 | 三态 |
|---|---|---|---|
| 起点年人均 GDP 实际增速 | **5.0%** | 2024 年人均 GDP 实际增长 **5.1%**（国家统计局公报）· 世界银行口径 2024 = 5.09% | 【官方】 |
| 近期潜在增速（2026—2030） | **4.93%**（区间 4.67~5.20） | 中国社科院《中国经济增长报告（2023～2024）》潜在增长率 | 【官方】 |
| 中期（2031—2040） | **2.8%** | IMF Working Paper 2024/238 · **无重大改革**基准情形 | 【官方·转引】 |
| 长期（>2040） | **1.2%** | **模型假设** —— 权威机构只给到 2040；取"接近发达经济体长期增速"的外推 | 【模型假设】 |
| 劳动收入弹性（TFP → 工资） | **1.0（先取 1，即生产率全部传导到工资）** | 长期劳动收入份额无趋势是主流经验事实；⚠ **本项未标定** | 【模型假设】 |
| 收入增速 = | 人均 GDP 实际增速 × 弹性 | — | — |

**分段函数**（`year` = 仿真年，自基准年起算）：
```
g(year) = 5.0%           year ∈ [0, 5)      ← 2026—2030（社科院 4.93% 取整 5%）
          2.8%           year ∈ [5, 15)     ← 2031—2040（IMF）
          1.2%           year ≥ 15          ← 2040 以后（模型假设）
TFP(year) = Π(1 + g(k))  k=0..year-1        ← 累积
```

### 2.2 死亡风险下降 / 期望寿命趋势

| 参数 | 取值 | 依据 | 三态 |
|---|---|---|---|
| 基准 e0（已有，不变） | **83.67 岁** | 上海 2020 户籍期望寿命（统计年鉴表2.1 / 卫健委） | 【官方】 |
| 中方案：2026→2050 目标 | **83.38 岁**（全国口径） | UN WPP 2024 中方案（**2050 = 83.38** · 2100 = 89.79） | 【预测·权威】 |
| 上海起点的外推 | **e0(2050) = 84.10** | 上海 2020 = 83.67 ⇒ 取 **83.67 + 0.43**（用 UN 全国 2020→2050 的增量 1.1 岁 × 上海"已高"折减 0.39）；⚠ **本折减是模型假设** | 【模型假设】 |
| 长期（2050→2100） | **+5.7 岁 / 50 年 ⇒ 0.114 岁/年** | UN WPP 全国 2050 = 83.38 → 2100 = 89.79 | 【预测·权威】 |
| 2100 以后 | **冻结**（不再上升） | 避免无根据外推（生物学上限未知） | 【模型假设】 |

**分段函数**：
```
e0(year) = 83.67 + (84.10 − 83.67) × min(1, year/24)        year ≤ 24   （2026→2050）
         = 84.10 + 0.114 × min(50, year − 24)               24 < year ≤ 74
         = 89.80                                            year > 74   （2100 以后冻结）
```

### 2.3 价格水平

| 参数 | 取值 | 依据 | 三态 |
|---|---|---|---|
| 长期通胀 | **2.0%/年**（与引擎现有 `e.inflation` 长期中枢 0.02 一致） | 引擎既有标定 + 主流央行目标 | 【平台】 |
| 短期波动 | **沿用 `e.inflation`**（现状变量，只当水平系数） | 引擎既有 | 【平台】 |
| 价格水平 | **P(year) = Π(1 + 0.02)**（累积） | 本层新增 | — |

⚠ **为什么不把 `e.inflation` 一起累积**：它是**周期波动**（`clamp(…, −0.03, 0.2)`），
累积它会变成随机游走并污染长期口径 ⇒ **短期波动仍只当水平系数，长期趋势单独用 2% 累积**。
⭐ **这条要写进 L-6**：**"累积价格水平"与"通胀系数"是两个不同的东西，不能混。**

### 3.1 ⚠⚠ 一次真实事故（**必须记住**）

```
❌ 第一版写法：`if (!city._life) city._life = lifeBuild(cityE0Target(年))`
              + `else { if (|存 − 目标| > 0.0005) 重建 }`
✅ 症状：**开关关闭时，生产路径的判据 A 偏离**（`E5567887AFFB70AB` ≠ `9018C2374EB44444`）。
   ⚠ 而**逐天/逐人对比查不出来**：两个引擎 200 天内 inc/wealth/job/alive 全等、数值指纹全等，
     **只有整体 demog 哈希不同**。
🔍 定位过程（值得复用）：
   ① **唯一变量对照**：同 harness 同环境 ⇒ 旧引擎命中基线、新引擎偏离 ⇒ 确认"在引擎侧"。
   ② 用 `git diff --no-index` 拿**完整行级差异**
      （⚠ `Compare-Object` 的 SyncWindow 会给出**假象**，本夜我被它误导过一次，别用）。
   ③ **正向二分**：从旧引擎出发每次只加一处 ⇒ 追到"`_life` 那一行"。
   ④ **唯一变量还原**：全量新引擎里只把那一行还原成旧写法 ⇒ **命中基线** ⇒ 元凶锁定。
⭐ 根因：`cityE0Target(...)` **每步都被求值一次**（即使开关关闭）。它返回的仍是 83.67，
   但**求值路径与旧写法不同 ⇒ 浮点结果不完全等价 ⇒ 扰动后续随机流**。
⇒ ⭐⭐ **纪律（新）："关闭时不变"要求【连求值都不能多一次】——
   不是"看起来等价"，而是【逐位同源】。**
```

**最终写法**（已通过判据 A 双路径）：

```js
if (!city._life) city._life = lifeBuild((CIV.CITY_VITAL && CIV.CITY_VITAL.lifeE0) || 83.67);  // ← 与旧代码逐字节相同
/* ★ 技术增长：**按年**重建生命表（关时整段不执行 ⇒ 连求值都没有） */
if (CIV.cityTechOn && CIV.cityTechOn()) {
  const _yr = Math.max(0, Math.floor(city.day / 365));
  if (city._techYr !== _yr) { city._techYr = _yr; city._life = lifeBuild(CIV.cityE0Target(_yr)); }
}
```

## 五、⚠ 如实声明（本层**不做**什么）

```
· ❌ **不做内生 TFP**（研发投入 → 生产率）—— 那与经济系统耦合 ⇒ 留给 ③
· ❌ **不做产业升级**（职业/行业结构随年代变迁）⇒ 结构仍冻结在 2024 横截面
· ❌ **不做迁移与教育的年代趋势**（学历队列仍按区文化程度表抽）⇒ 与技术进步只有单向联系
· ❌ **不把"名义/实际"接进政府账本** —— 接口已给（`cityPriceLevelOf`），
     但把 `treasury` 拆成两个口径是**政府层**的改动 ⇒ 需单独决定（本层只提供指数）
· ⚠ **参数 g(>2040) 与 e0 的"上海折减 0.39"是模型假设**，不是官方数
· ⚠ 本层**会改行为**（开关开启时）⇒ 判据 A 基线会变 ⇒ 必须记新基线 + 更正块
```
