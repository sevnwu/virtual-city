## 〇、为什么（用户 2026-10-08 确认）

> **"线上 54 万人不是因为真的 54 万，而是服务器顶不住，所以 54 万人代表 2400 万人。"**

⇒ **标度 = 2400 万 ÷ 54.7 万 ≈ 43.9**，而 `minPopulation` 是**真实世界标准**
（`subway` 300 万 = 国办发〔2018〕52号）⇒ 若按虚拟人口判 ⇒ **误判**：

| 领域 | 门槛 | 按虚拟人口（547,010） | 按真实人口（24,013,739） | 线上现值 |
|---|---|---|---|---|
| **`subway`** | **3,000,000** | 🔴 **缺席** | ✅ 存在 | **3** |
| **`green`** | **600,000** | 🔴 **缺席** | ✅ 存在 | **2** |
| `hospital` | 500,000 | ✅ 存在 | ✅ 存在 | 3 |
| `school` | 50,000 | ✅ 存在 | ✅ 存在 | 3 |

⇒ ⇒ 🔴 **所以「启用 `SIZE_GATE` 而不设标度」会让线上【地铁消失】**（3 → 1）❗

## 一、改动（**单点 + 注入**）

### ① 引擎 `js\citysim.js`

```js
function popScale() {
  const _s = (typeof CIV !== 'undefined' && CIV.CITY_POP_SCALE != null) ? Number(CIV.CITY_POP_SCALE) : 1;
  return (isFinite(_s) && _s > 0) ? _s : 1;
}
function domainAbsent(city, kind) {
  if (!sizeGateOn()) return false;
  const _mp = minPopOf(kind);
  if (_mp <= 0) return false;
  return (((city && city.aliveCount) || 0) * popScale()) < _mp;   // ★ 唯一改动
}
```
+ 导出行加 `popScale`（`L9079` 附近）。

⭐ **为什么单点就够**：`domainAbsent()` 是**唯一的比较点** ——
四处下游（晋升闸门 · 真算维护 · 探针）**全部经由它** ⇒ 改这一处即**全局一致**，
不会出现"真算与探针不一致 ⇒ 判据骗过自己"。（与 `GREEN_GATE` 同一模式。）

### ② harness `tools\_soul_test.cjs`

宿主注入 + **双向留痕**（开与关都打印 `[人口标度] …`）——
即"第 N 类静默失效（开关从未进入 env）"的防线。
