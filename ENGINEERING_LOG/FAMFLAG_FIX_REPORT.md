## 一、用户看到的现象

市民 `VP945222`（程婷 · 女 · 61 岁 · **未婚**）的「生活/工作轨迹」：

```
第 1980 天：开始独居生活（配偶已故/无同住家人）
第 1950 天：开始独居生活（配偶已故/无同住家人）
第 1920 天：开始独居生活（配偶已故/无同住家人）
第 1620 天：开始独居生活（配偶已故/无同住家人）
```

两个毛病：**① 同一条"一次性"事件重复记 4 次** · **② "未婚"的人却显示"配偶已故"**。

## 二、根因（两类）

### ① 去重标记没有持久化 ⇒ 每次重启重新武装

```
旧实现（js/citysim.js:6096-6097）：
   if (!city._famLogged) city._famLogged = new Set();
   const once = (id, kind) => { … city._famLogged.has(k) … };
```

* `city._famLogged` 是一个 **`Set`**，**不在快照的 `ARR` 白名单里**（`city_server.js` 命中 0 处）。
* 快照只存 **JSON meta + 类型化数组**（`CITY_NO_SNAP` 之外的 `ARR` 56 项）⇒ **`Set` 既不写也不读**。
* ⇒ 服务器每次重启，这个 Set **重新变空** ⇒ 同一件"一次性"事件在【重启后的第一个月结】又被记一遍。
* **与时序吻合**：4 条 = 当天那几次部署重启所跨过的月结（`11:11→1920` · `12:40→1950` · `13:51→1980` · 更早一次 `→1620`）。

**⚠ 同函数内三个事件同病**：`leavehome`（离家）· `grandcare`（带孙辈）· `livesalone`（独居）—— 共用同一个 `once` / 同一个 Set。

### ② 文案是"手写斜杠把两种情况凑一句"

```
js/citysim.js:6158（旧）：
   … logLife(city, i, 'livesalone', '开始独居生活（配偶已故/无同住家人）');
```

固定字面量 ⇒ **未婚的人也会显示"配偶已故"**。

## 三、改了什么

### ① 引擎：`Set` → **按人 1 字节的标志位数组** `city.famFlag`（`js/citysim.js:6094-6119`）

```js
const _fl = city.age.length;
if (!city.famFlag || city.famFlag.length !== _fl) {
  const g = new Uint8Array(_fl);
  if (city.famFlag) { const m = Math.min(city.famFlag.length, _fl); for (let i = 0; i < m; i++) g[i] = city.famFlag[i] | 0; }
  city.famFlag = g;
}
const once = (i, mask) => { if (city.famFlag[i] & mask) return false; city.famFlag[i] |= mask; return true; };
```

* **位定义**（只能往后加位）：`bit0 = leavehome` · `bit1 = grandcare` · `bit2 = livesalone`。
* **按长度自适应**：快照载入后是普通 `Array`（`city_server.js` 用 `Array.from(t)`）、新生儿/迁入者没有槽位 ⇒ 长度不符就重建并保留旧值；新槽位 = 0 = 未记（正确）。
* **调用点三处**（`id` 键 → 下标 + 位掩码）：`:6141 once(i, 1)` · `:6164 once(i, 2)` · `:6183 once(i, 4)`。

### ② 引擎：`compact()` 重排列表加 `'famFlag'`（`js/citysim.js:6905` 一带）

⚠ 这一步**不能漏**：`famFlag` 是按下标的数组，不随 `age` 重排 ⇒ 移除死者后**下标错位** + **数组永不收缩**（与 `civic` 那次同款的后果）。

### ③ 服务端：`ARR` **末尾追加** `['famFlag', 'U8']`（`city_server.js:199`）

⇒ 标志位随快照往返 ⇒ 重启不再重复记。`loadSnapshot` 对缺失的尾部数组本就有"读不到就跳过"的处理 ⇒ **旧快照天然向后兼容**。

### ④ 文案：按真实婚姻状态分支（`_loneWhy`，`js/citysim.js:6112-6119`）

```
mstat = 3 丧偶  ⇒ 「开始独居生活（配偶已故）」
mstat = 0 未婚  ⇒ 「开始独居生活（未婚 · 无同住家人）」
mstat = 2 离异  ⇒ 「开始独居生活（离异 · 无同住家人）」
mstat = 1 已婚  ⇒ 「开始独居生活（未与配偶同住）」
其它/缺失       ⇒ 「开始独居生活（无同住家人）」
```

（`mstat` 口径见 `js/citysim.js:3151`：0 未婚 · 1 已婚 · 2 离异 · 3 丧偶 —— **已有且持久化**，不新增状态。）
