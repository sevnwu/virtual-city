```

## 二、⭐ 三条硬约束（**先写清楚，否则后面会自相矛盾**）

```
约束 1 · **唯一收入出口**：工资必须仍然只由 `incomeOf()` 产出。
   ⇒ 经济系统**不得**在别处再加收入（本轮之所以出 "TFP²" 事故，就是因为同一件事做了两次）。
约束 2 · **单一施加点**：所有"生产率/资本/价格"的调整，**只在链尾包装层施加一次**。
   ⇒ 新增乘数一律走 `cityEconMulOf(year)` 之类**单一函数**，禁止散落进公式。
约束 3 · **默认关 + 关时逐位同源**：不做"看起来等价"的改写。
   ⇒ 教训：判据 A 曾经因为"关闭时仍多调用一次求值"而失败 ⇒ 本次**任何新求值都必须先判开关**。

## 四、规则（最小集 · 每一条都可开关）

### 4.1 生产与劳动需求（Cobb-Douglas）
```
Y = A · K^α · L^(1−α)                     α = **0.48**（权威机构·转引 · 收入法 GDP ⇒ 见 §〇）
w* = (1−α) · Y / L                        ⇒ 均衡工资
工资调整（避免瞬间跳到均衡 · 有摩擦）：
  wIdx(t+1) = wIdx(t) · (1 + λ · (w*/w − 1))     θ_m = **0.126/月**（学术文献估算 · Calvo θ=0.33/季度 ⇒ 见 §〇）
⇒ ⭐ 这一层**只调"相对工资指数"**，绝对水平仍由 `incomeOf` 锚定年鉴值
```

### 4.2 投资（内生积累的来源）
```
留存 = Y − 工资总额 − 税                 （税沿用政府层 `taxOf`，**不重复造**）
投资率 = **0.33**（权威机构 · WB WDI 固定资本形成 39.7% of GDP 扣居民住宅 ⇒ 见 §〇）
ΔK = 投资 − 折旧 · K        折旧率 = **0.10/年**（学术文献估算 · PIM 10.96% ⇒ 见 §〇）
⇒ ⭐ **这就是"内生积累"的通道**：投资 → K↑ → Y↑ → 工资↑ → 再投资
```

### 4.3 研发与"积累 → 突破"（**用户明确要求的内生路径** · ⭐ **已实现**）

```
研发强度 rd = rdFirmShare × invRate × rdShare
   rdFirmShare = 0.777  【官方】2024 全国企业占 R&D 77.7%
   invRate     = 0.33   【权威机构】WB WDI 固定资本形成 39.7% of GDP 扣居民住宅
   rdShare     = 0.30   ⚠【模型假设】企业留存中投研发的比例
   ⇒ rd = 0.0769

知识存量（相对建仓年的对数增长）：
   ln Z(t)/Z(0) = (knowEta · rd − knowDecay) · t      ← **闭式解 · 无状态推进**（吸取步骤 4 的路径依赖教训）
   knowEta   = 2.4  ⚠【模型假设】但**可标定**：取"知识存量翻倍约 20 年"，与"技术换代 20~40 年"相称
   knowDecay = 0.15 ⚠【未找到】中国无官方统计、无权威估计 ⇒ 文献惯例假设
```

**突破判定（内生触发 · 不给年份）**：
```
每跨一个阈值 θ_k ⇒ 生产率**永久**乘 (1 + btGain)
   btFactor(t) = (1 + btGain)^(已跨越阈值个数)
   btThetas = [2, 4]   ⚠【模型假设】用**无量纲相对量**（"翻倍 / 再翻倍"），
                        因为**未找到**权威的"知识/专利存量阈值"数值
   btGain   = 0.04     ⚠【模型假设】每次突破的生产率永久提升
默认参数下的时序：**翻倍周期 20.0 年** · y20 Z=2.00（边界）· **y21 首次突破 θ=2** · y50 第二次 θ=4
```

### 4.3.1 🔴🔴 设计教训：**"连续乘" vs "阶跃"**（这一步的第一版是错的）

```
❌ 第一版：`factor = Π (1+btGain)^(y − 跨越年 + 1)`
   ⇒ 把知识存量**连续地**乘进生产率 ⇒ 两个后果：
     (a) 它变成**又一条连续的 TFP 通道** —— 与 2026-10-10 修掉的"TFP 双乘"**同类**：
         同一件事（生产率提升）被"外生 TFP"与"知识存量"两处同时施加。
     (b) **敏感度极高、且时机被一个无来源参数支配**：
         η=2 ⇒ 知识翻倍要 **180 年**（等于永不突破）；η=5 ⇒ 翻倍 **3 年**（过快）
         ⇒ 突破何时发生、幅度多大，**全由 η 决定** ⇒ 这不是"建模"，是"用参数当结论"。
✅ 第二版（现在）：**阶跃 + 两个旋钮分离**
     · 知识存量 **只决定何时** 跨阈值（时机）
     · `btGain` **单独决定幅度**（每跨一次给一次永久加成）
     ⇒ η 只影响时机、btGain 只影响幅度 ⇒ 两者**互不掩盖**，可以各自做敏感度
```

⭐ **本步已与前两项（漂移 / 资本）一起进入三项分解**：`obs ≈ drift × tech × cap × bt`
⇒ 每一层的贡献都能单独读出，不会被别的通道顶替。

**突破判定（内生触发，不给年份）**：
```

  能源/电力   W=10 年   突破判据：可再生能源装机占比 ≥ 25%（**官方规划口径**）
  AI/自动化   W=5~8 年  突破判据：机器人密度 > 500 台/万名制造业员工（**IFR 口径**）
  医疗/生物   W≥15 年   突破判据：人均预期寿命 ≥ 80 岁（**官方口径**）
  先进制造    W=12~15 年 突破判据：集成电路年产量量级 / 锂电包价格 < $100/kWh（**BNEF 口径**）
触发：Z_d ≥ θ_d 持续 W_d 年 ⇒ 该方向生产率跳升（幅度可标定，**模型假设**）

    |---|---|---|---|
    | finalOff（对照·TFP≡1）| ×28.0 | **4.95** | 1.309 |
    | finalOn（技术）       | ×90.5 | **8.69** | 4.174 |
  ⇒ 若把 `(K/L)^0.48` 直接当乘数接上，工资会涨 **5~8.7 倍** —— 比观测到的 4.17 还夸张。

🔴 **根因**：资本代理是 `人均财富 × 人口`，而**财富本身是内生的**
   （收入 → 储蓄 → 财富 → `assetPlMean` 资产收益 → 更多财富）
   ⇒ 用内生财富去算 Cobb-Douglas 的资本深化 = **自我循环 / 把同一个因素算两次**
   ⇒ 这与"TFP²"、"通胀双扣"是**同族错误**（2026-10-10 一天内第 4 次遇到这个模式）。

✅ **由此确立硬设计规则（本设计新增约束 4）**：
   **❌ 不得用"住户财富"当生产函数里的 K。**
   住户财富的积累已由 `assetPlMean` 路径处理；再乘 `(K/L)^α` 即重复计数。
   **✅ 生产函数的 K 必须是独立的生产性资本存量**：只由**企业投资**积累、
      与住户财富【分离记账】（`city.econ.K` 与 `city.wealth[]` 是两本账，**不互通**）。

⭐ **另一条实测发现（对已上线特性也成立）**：
   `finalOff`（TFP 恒为 1）的 `avgIncome` 从 y0 到 y19 涨了 **1.309 倍**
   ⇒ **这条 31% 的涨幅来自户级/资产反馈，与 TFP 无关**（内生的放大器）。
   因此"技术增长"的体感强度 = TFP × 内生放大器 ⇒ 比 TFP 本身强。
   ⚠ 这是**已知特征**（不是 bug），但**必须在文档与版本说明里写明**，否则会被误读成"TFP 算错了"。
```

## 九、参数定案（**已查证 · 已写入引擎默认值**）

> ⭐ 本节原为"待确认的三个假设值"，**现已由真实口径查证替换** ⇒ 汇总见 **§〇**。
> 保留本节仅为记录**推理过程与更正**（§9.1 的原推理已被证伪，见 §0.1）。

### 9.1 资本份额 α —— **原推理错误，已更正**

```
❌ 原推理："上海三产占 3/4 ⇒ 服务业劳动份额高 ⇒ α 取 0.45（区间下半段）"
✅ 实测更正：**上海 α ≈ 0.545~0.566**，**高于**全国 0.44~0.48
   （上海劳动者报酬占地区 GDP 43.4%(2014)→45.5%(2017)；全国 52.1%(2020)）
   原因：上海是**生产性/金融服务业 + 总部经济** ⇒ 营业盈余极高。
   **"劳动份额高"的是生活性服务业 —— 我把两类混为一谈了。**
⇒ 定案 **α = 0.48**（全国收入法口径）· 备选：PWT 0.44 / 三产 0.472 / 上海 0.545
```

### 9.2 工资粘性 —— **改用 Calvo 口径（原 λ 平滑收敛被替换）**

```
❌ 原设计："λ = 0.15/月 平滑收敛，半衰期 4.3 个月"—— 是我拍的假设
✅ 实测：Calvo **θ = 0.33/季度**（侯成琪等 2018《统计研究》）
   ⇒ 月调整概率 = 1 − (1−0.33)^(1/3) ≈ **0.126** ⇒ 平均调薪间隔 ≈ **4.5~7.9 个月**
   ⚠ 与"制度性最低工资 24~36 个月"（人社部）**差 5~8 倍** —— 本模型模拟**企业调薪** ⇒ 用 Calvo
⇒ 定案 **θ_m = 0.126/月**（机制也随之从"平滑收敛"改为"**粘性 + 离散调整**"）
```

### 9.3 实际利率 / 通胀接法 —— **不动 `assetPlMean`**（见 §5.1 更正）

```
❌ 我原提的"r_real = 3% − π"**已作废**（重复扣通胀 —— 与 TFP² 同类错误）
✅ 定案：`assetPlMean = 3%` 保持为**实际收益**；通胀抑制**只走决策通道**（投资率 / 结余率）
⇒ **零既有标定改动** ⇒ 风险最低
```

### 9.4 外生 TFP：**baseline 保留 + burst 可切换**

```
现状：`5.0%（2026–2030）/ 2.8%（2031–2040）/ 1.2%（2040–）`，三态 =【官方】/【IMF】/【模型假设】
⭐ 定案：**不删不换**，把情势做成可选包（`CITY_TECH_SCENARIO`）：
    · `baseline`（默认 · = 现值）：5.0 / 2.8 / 1.2
    · `burst`（用户要的"积累→突破→滞停"）：
        积累期 2026–2032 **2.5%** · 突破期 2033–2040 **6.5%** · 平台期 2041– **0.8%**
      依据：`TECH_TREND_SIGNALS.md` 的前置窗口（能源 10 年 / AI 5~8 年 / 医疗 ≥15 年 / 制造 12~15 年）
      ⇒ 取较短窗口定 7 年积累期；**医疗方向另走内生积累**（≥15 年，与外生不同步）
    · 理由：情势是**情景不是事实** ⇒ 必须有 baseline 做对照，否则**判据 E-C 无法成立**
```
