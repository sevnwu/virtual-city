## 〇、先纠正任务前提（**这是本报告最重要的一节**）

任务书的判据 C 是"**建一次落在 10~30 年**"，其依据是"REALCOST 修过头"。**该前提不成立**：

```
⭐ **纯算术**：若 一级物理量 = 人均指标 × 人口 ÷ 5
   ⇒ 资产 = 一级物理量 × unitPrice ∝ 人口
⭐ 而税收 ∝ 人口（已由上一班实测确认）
⇒ ⇒ ⭐⭐ 所以"资产 ÷ 年税"是【与人口无关的常数】⇒
   **"人均缩放"不会让"建一次"变快或变慢** —— 它修的是【别的东西】 ✓
```

**⭐ 现实对照（决定性）**：

| | 资产 / 年财政收入 |
|---|---|
| **上海（真实）**：公园绿地全存量 5,200 元/人 ÷ 人均财政收入 30,560 元/人年 | **0.17 年** |
| **模型（满级绿地存量）** | **0.150 年** |

```
⇒ ⇒ ⭐⭐ **"钱不够"【不是】真实世界里绿地的约束** —— 约束是【土地 · 规划 · 时间】✓
⇒ ⭐ 所以「财政约束在任何规模下都不 bind」这个实测结论【与真实世界一致】·
    **不是"没修好"** ✓✓
⇒ ⚠⚠ **本次修正【不追求】让财政 bind** —— 人为制造紧张会把真实世界的结论弄反 ✓
```

**⇒ 而真正的错【只有一条】**：
```
🔴 **"2,500 人城市被要求建 500 公顷绿地"**（满级 2,500 公顷 ⇒ **人均 10,000 ㎡ = 国家标准的 1,250 倍**）
   ⇒ ⭐ **修法正是【人均缩放】** ✓✓
```

## 二、改动（**一处算 · 三处读 —— 解决了"两套价格"**）

### ⭐ 共享函数（`CIV.cityGov` IIFE 内 · 唯一来源）

```js
const _PER_CAP = {
  subway:   { v: 1.33e-4, tier: '模型假设' },
  hospital: { v: 6e-6,    tier: '模型假设' },
  school:   { v: 6.67e-5, tier: '模型假设' },
  green:    { v: 8e-4,    tier: '官方' }
};
CIV.__govUnitScale = function () { return !!(CIV.CITY_GOV_UNIT_SCALE); };
CIV.__govCapAsset = function (kind, pop) {
  const pol = COSTS.policies[kind];
  const price = pol.unitPrice.value, unitOld = pol.unitPhysical.value;
  if (!CIV.__govUnitScale()) return unitOld * price;      // 关 ⇒ 旧行为
  const pc = _PER_CAP[kind], n = (pop > 0) ? pop : 0;
  if (!pc || n <= 0) return unitOld * price;              // 无锚/无人口 ⇒ 退回旧值
  return (pc.v * n / 5) * price;                          // ⭐ 随规模缩放
};
```

**⭐ `÷5` 而不是 `÷6`**：`COST_BASE` 说"**1 级 = 0 资产**" ⇒ 1~6 级只有 **5 个增量**。
用 `÷6` 会让"1 级"非零 ⇒ **与 `COST_BASE` 冲突**。

### ⭐ 三处消费点全部改为读它（**这是"同源"的实质**）

| 位置 | 用途 | 改动 |
|---|---|---|
| `costOf`（L8912-8914） | **接口查询** | `amount = CIV.__govCapAsset(kind, _pop) × d` |
| `govStep` 真算维护（L8970） | **真算** | `_amt = CIV.__govCapAsset(k, aliveCount) × max(0, lv−_cbase) × rate / 12` |
| **探针**（L9040） | **对外报数** | 同上 ⇒ ⭐ **否则"探针骗过自己"** |

### ⭐ 建设侧（`autoPolicy` 的 `_bCost`）

```js
const _bCost = function (k, pop) {
  if (typeof CIV.__govUnitScale === 'function' && CIV.__govUnitScale()) {
    const _p = (pop > 0) ? pop : ((city && city.aliveCount) || 0);
    return CIV.__govCapAsset(k, _p);       // ⭐ 与维护侧同一个函数
  }
  return (CIV.CITY_GOV_REALCOST && _capAsset[k]) ? _capAsset[k] : _capOld[k];
};
```
**⇒ 13 个调用点全部传入 `city.aliveCount`**（闸门候选 4 处 + `ok()`/`spend()` 8 处 + `develop` 旁路 1 处）。

**⚠ `stimulus`(8e7) / `babyBonus`(6e7) 保持不变**（非 capital 族 · `gov_costs.json` 无对应资产）✓
