# 服刑期间房贷怎么办？—— 银行在模型里会怎么做

**日期**：2026-10-09（深夜）· **性质**：只读诊断 + 定向实验 · **未改任何文件** · **零部署**
**起因**：用户问「一个人因犯罪被关押，房贷没还完怎么办？银行会不会有行动？现在有银行系统管这个吗？」
**受检引擎**：`js\citysim.js` = `87F1DF78B3419A16`（648,137 B · 本地与线上一致）

---

## 〇、三句话结论

```
① ⭐ **没有"银行系统"** —— 全部房贷只有【家庭账本里的两行算术】，没有信用分、没有逾期台账、
   没有催收、没有罚息、没有展期、没有保人、没有个人破产程序（L-6「无经济系统」）。
② ⭐ **但"无力偿还"那一步【有】银行动作**（`citysim.js:3964-3994`）：**住房被处置** ——
   贷款清零 · 只拿回**净值的一半**（法拍折价口径）· **5 年内不得再购房**。
③ ⭐⭐ **它【与"坐牢"无关】** —— 判据是 `财富 + 12×月收入 < 0`，
   **不看任何犯罪/在押字段** ⇒ 失业、重病、经营失败**走的是同一条路**；
   而**在押确实是触发它的最强路径之一**（第 2 步就把 `job` 清成 −1、收入置 0）。
```

## 二、⭐ 触发处置的判据（原文）

```js
// citysim.js:3970-3972
if (LV2('milestones') && city.own && city.own[i]) {
  const abilityM = Math.max(0, city.wealth[i] || 0) + incM * 12;   // 全部积蓄 + 一年收入
  if (w + abilityM < 0) {                                          // 连它都盖不住当月支出
    … 处置 …
  }
}
```

⭐ **关键三点**：
1. **判据里没有一个犯罪/在押字段** ⇒ **银行"看不见"你在坐牢** —— 它只看钱。
   ⇒ 失业、重病、资产下跌**同路**（这既是缺陷，也是**口径上的诚实**）。
2. **在押确实是最强触发路径之一**：`incM = 0` ⇒ `abilityM` 只剩积蓄 ⇒ 积蓄耗尽即触发。
3. ⚠ 但**不是"一关就马上没房"**：① 仍按**天**扣（`econreal` 开时 `MS=1/24±`），
   ② 家庭账本用**户收入** ⇒ **若配偶有收入且能覆盖月供，什么都不会发生**。

### 处置的后果（全部实测自代码）

| 项 | 内容 |
|---|---|
| 住房 | `own[i] = 0`（**夫妻共同产权一并清掉**：`own[配偶]=0`） |
| 债务 | `mortgage[i] = 0` · `mortgagePay[i] = 0`（**贷款一次性清掉**，不留欠款） |
| 到手 | **净值 × 0.5**，其中 `净值 = 该区房价×面积 − 剩余贷款`（注释明写"法拍/急售折价"） |
| 冷却 | `noBuyUntil[i] = day + 365×5` ⇒ **5 年内不得再购房**（配偶同样记 5 年） |
| 记录 | 写进个人轨迹：`因无力偿还按揭，住房被处置（净值约 X 元，5 年内不得再购房）` |

## 五、回答"有没有银行系统"

```
❌ **没有银行系统**（L-6 已记「无经济系统」）。具体缺的：
   · 没有信用分/征信 · 没有逾期天数台账 · 没有催收/宽限期 · 没有罚息 · 没有展期重组
   · 没有保人/共同借款人规则（配偶只是分摊月供，不是法律意义上的共同债务人）
   · 没有个人破产程序（`bankrupt` 标记是**医疗自付**通道的产物：`:3999`，与房贷无关）
✅ **有的**：一个"还不起就处置"的**单步兜底**，加上：继承（`settleEstate`）、
   离婚析产（按 `mortgagePaid` 贡献分）、提前还款（`lastPrepayDay` 每年一次）、父母帮月供。
⚠ **最该补的（如果以后要做"银行"）**：**逾期与宽限**（现在从"照扣"直接跳到"处置"，
   中间没有任何可观测状态）—— 这也是用户这个问题的真正答案：
   **模型里"银行"不会先做任何事，它只会在你彻底还不起时把房子收走。**
```
