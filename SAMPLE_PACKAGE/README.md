## 这个包是什么

一个**行为级虚拟城市**在若干年运行后的**抽样导出**。与常见的统计型人口模型不同，
这里每个个体有：

- **身份**：`sid`（灵魂号，跨世不变）· `bid`（身体号，每世一个）· `gen`（第几代）
- **人格**：`O/C/E/A/N` 五维（大五人格）· `arche`（原型分型）
- **一生**：`birthDay` / `deathDay` / `ageAtDeath` / 逐年状态 / 事件流
- **社会关系**：恋爱、婚姻、生育、离异、丧偶、再婚（`mstat`）
- **社会经济**：`edu`（学历）· `health` · `job` · `inc`（收入）· `dist`（居住区）

**"灵魂"与"身体"分离**是本系统的一个设计：性别是身体的属性、随世改变；
而人格与跨世记忆挂在灵魂上。所以同一个 `sid` 会有多个 `life`（＝投胎转世）。

### 四个文件的粒度关系

```
sample_demog.csv   ← 城市（1 行 = 1 年）
sample_souls.csv   ← 灵魂（1 行 = 1 个 sid，跨世汇总）
sample_panel.csv   ← 人·年（1 行 = 1 个 bid 的 1 年）      ← 做统计最常用这张
sample_lives.jsonl ← 人·一生（1 行 = 1 个 bid 的完整一生）  ← 做质性/序列分析用这张
```

**同一个体在四张表里靠 `sid` / `bid` 关联**（`souls.sid` ↔ `panel.sid` ↔ `lives.sid`；
`panel.bid` ↔ `lives.bid`）。

## 怎么用

```bash
# 面板回归 / 描述统计（人·年粒度）
python -c "import pandas as pd; d=pd.read_csv('sample_panel.csv'); print(d.describe())"

# 一生序列（人·一生粒度 · JSON Lines）
python -c "
import json
for i,l in enumerate(open('sample_lives.jsonl',encoding='utf-8')):
    o=json.loads(l); print(o['sid'],o['life'],o['ageAtDeath'],len(o['events']))
    if i>=4: break"

# 城市年度指标
python -c "import pandas as pd; print(pd.read_csv('sample_demog.csv')[['year','pop','births','tfr']].tail())"
```

**字段字典、生成方法、可复现性参数、已知限制 ⇒ 见 [`../DATA_SPEC.md`](../DATA_SPEC.md)。**
