## 一、四个可选定位

### (a) 学术免费 + 商业收费 ⭐（最常见 · 建议起点）

```
学术/教育用途：免费（需署名 + 引用）
商业用途：需授权（按项目 / 按年 / 按数据集）
```
**后果**：
- ✅ 学术圈会用它 → **论文被引用** → 这是"飞轮"的启动点
- ✅ 商业客户有明确路径（不用重新谈判）
- ⚠ 需要写清"**学术 vs 商业**"的界线（很多机构是混合性质）
- ⚠ 需要一份**可执行的授权模板**

---

### (b) 完全开源（数据 + 可能含引擎）

```
任何人可自由使用、修改、再分发
```
**后果**：
- ✅ 影响力最大 · 建立标准 · 容易被引用
- ✅ **不需要谈授权** ⇒ 交付成本最低
- ❌ **难变现** —— 别人可以基于它做商业产品而无需付费
- ⚠ 一旦开源**不可撤回**（已分发的副本收不回）
- ⚠ 若含引擎代码，需先确认**引擎里有没有不能公开的部分**（如姓名库来源）

---

### (c) 全闭源 · 只卖服务（不交付数据）

```
数据不分发；只卖"分析结论"或"按需生成的定制数据集"
```
**后果**：
- ✅ 保护性最强 · 单价可以最高
- ❌ **无法被引用** ⇒ 学术飞轮转不起来
- ❌ 客户无法独立验证 ⇒ **成交周期长**
- ⚠ 与"论文介绍系统"的策略**部分冲突**（论文需要可复现的公开材料）

---

### (d) 分层：样例开放 + 完整集收费 ⭐⭐ ✅ **已采纳（2026-10-07）**

```
⭐ 样例包（本目录）：CC BY 4.0 ⇒ 免费 · 署名即可 · 可引用 · 可转载 · 可用于商业原型
   ⚠ 注意：拍板时【没有】选 CC BY-NC —— 理由见下方「为什么不用 NC」
完整批次：商业授权（定价待定）
引擎：All rights reserved（闭源）
```
**后果**：
- ✅ **兼顾"被引用"与"能变现"**
- ✅ 样例包本身就是**销售材料**（客户看完就知道要不要买）
- ⚠ 需要维护**两套交付物**（样例 / 完整集）
- ⚠ 需要明确"样例与完整集的差别"（避免误解为完整集也可免费拿）

**⚠ 为什么最终用 `BY` 而不是 `BY-NC`（2026-10-07 决策）**：
```
⚠ `NC` 会挡住：**公司内部试用 · 教学 · 咨询公司做原型** ⇒ 而那【正是潜在客户】❗
✅ `BY` 只要求**署名** ⇒ 而**署名正是我们最想要的**（传播的痕迹）
⭐ 商业化保护【不靠许可】⇒ 靠 ① 引擎闭源 ② 样例只有几千行 ③ 定制服务 ✓
```

## 二、🔴 三个必须一并决定的问题

### ① 定价锚

可选锚点（**只能选一个当主锚**）：
```
· 按【数据集规模】   —— 如"每 10 万虚拟人 × 10 年 = X 元"
· 按【用途】         —— 如"学术 X 元 / 商业 Y 元 / 独家 Z 元"
· 按【项目】         —— 顾问式，按问题报价（单价最高 · 最难规模化）
· 按【订阅】         —— 年度会员，可下载全部数据集
```
⚠ **没有市场参照** ⇒ 建议**先用"按项目"试水 2~3 单**，再定标准价。

### ② 署名与引用

```
· 作者/机构写谁？✅ **已暂填 `sevnwu`**（`README.md` / `README_EN.md` / `DATA_SPEC.md` 的 BibTeX）
  ⇒ ⚠️ **正式发布前建议改成真名或机构名**（学术引用需要可核实的作者名）
· ✅ **联系方式已定**：`wudonghai@126.com`（**接受合作与数据申请**）
· 是否要求"使用时必须引用某篇论文"？（若要求 ⇒ 那篇论文必须先写出来）
· 是否允许客户在成果中不提数据来源？
```
⚠ **这一条与飞轮直接相关**：若允许不署名，引用数上不去，学术飞轮就不转。

### ③ 是否提"上海"

```
· 数据里 `city = "sh"`（见 manifest.json）
· ⚠ 若对外称"上海"⇒ 容易被理解为"对上海的预测" ⇒ 与"不能预测"的定位冲突
· 可选表述：「以某超大城市为参照的量级设定」/「城市 A」
```
⚠ 这一条**同时影响法律风险与学术可信度**，建议保守表述。
